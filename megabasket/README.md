## 조사 결과 → 연출 반영

| 조사에서 확인된 점 | 영상에 반영한 방식 |
|---|---|
| 댓글 반응의 중심은 **가격** (“정말 싼데여??????”, “와 개싸다”) | 첫 0.25초에 “식당 사장님들만 쓰던 **그 가격**” → ‘도매가’ 도장. 가격 궁금증으로 훅 |
| 외부 댓글의 69%가 **친구 태그·동행 제안** | 마지막 CTA를 “같이 갈 사람 **태그!**” + 댓글창 타이핑 연출로 |
| “어디세요” 위치 질문 | 상단에 ‘광주 매월동’ 고정 표시 + 지도 핀 장면 + 엔드카드까지 주소를 3번 노출 |
| “카드결제 못해요” 결제 문의 | 숨기지 않고 ‘싼 이유 01’로 전환: 현금·계좌이체 전용 → 카드 비용 아낀 만큼 가격↓ |
| 1,400평 vs 700+500평 **면적 안내 충돌** | 면적 숫자는 사용하지 않음 |
| 쿠팡·다이소 대비 표현은 **미검증** | 사용하지 않음. 매장 공식 문구 “온라인보다 싸게”만 쓰고 비교 기준 각주를 붙임 |
| 보고서 권장 순서: 가격 → 품목 → 위치·주차 → 결제·영업시간 | 장면 순서를 그대로 따름 |

## 기억에 남게 만든 장치
- **같은 문장 3번 반복**: “도매가격, 일반인도 똑같이”를 오프닝·요약·엔드카드에 반복
- **숫자로 외우기**: `7 ~ 8` (아침 7시~저녁 8시) + `365일` 카운터
- **3줄 요약 체크리스트**: 끝나기 직전 “딱 3개만 기억!”
- **빠른 전환**: 장면당 0.4~2초. 120BPM 비트에 맞춘 컷·화이트 플래시·휩팬·원형/바 와이프

## 게시 전 확인할 것
- 영업시간·주차·결제·현금영수증 문구가 **현재 매장 운영과 같은지** (조사 시점 기준 문구를 사용)
- “온라인보다 싸게”는 매장 공식 문구이지만, 동일 상품·규격·수량 비교 근거를 갖고 쓰는 것이 안전합니다
- 효과음·비트는 외부 음원 없이 직접 합성했습니다. 인스타그램 음악을 쓰려면 앱에서 원본 오디오 볼륨을 내리고 음악을 추가하세요

## 다시 렌더링하기
문구·타이밍은 `index.html`의 장면 함수(`S.s1` ~ `S.s10`)와 `CUES`(효과음 큐)에서 수정합니다.
```bash
node megabasket/tools/render.cjs                       # 영상 + 효과음 + 커버 생성 (약 1분)
node megabasket/tools/render.cjs --frames 0.5,5.5,24   # 특정 시각 PNG만 저장 (검수용)
```
필요: Node + Playwright(Chromium), ffmpeg, Python 3 + numpy.
폰트: Pretendard, Black Han Sans (둘 다 SIL OFL, `fonts/` 안에 라이선스 포함).
