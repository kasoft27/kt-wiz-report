# KT Wiz Live Report & KBO Dashboard

KT 위즈 프로야구 경기 리포트 및 KBO 순위 웹 대시보드입니다.

## 🚀 GitHub Pages 1분 배포 가이드
1. GitHub에서 새로운 저장소(Repository)를 생성합니다. (예: `kt-wiz-report`)
2. 본 폴더의 파일들(`index.html`, `.github/` 폴더 등)을 해당 저장소에 업로드(Commit & Push)합니다.
3. 저장소의 **Settings** 탭 ➡ 좌측 **Pages** 메뉴로 이동합니다.
4. **Build and deployment** 항목의 **Source**를 `Deploy from a branch` (Branch: `main`, Folder: `/ (root)`) 또는 `GitHub Actions`로 설정하고 저장합니다.
5. 약 1분 후 `https://<사용자아이디>.github.io/kt-wiz-report/` 형태의 고유 URL이 생성되며 상시 접속 가능합니다!
