단톡방 대화 → 표 한 장

📦 카톡 발주·품목 정리기

단톡방 대화를 붙여넣으면 발주·품목보고를 품목/수량 표로 정리해 드려요.

🔒 넣은 대화는 이 브라우저 안에서만 처리돼요. 인터넷으로 보내지 않아요.

1카톡 대화 넣기

내보낸 .txt 파일을 위 칸에 끌어다 놓아도 돼요. 여러 방을 차례로 넣으면 표에 계속 쌓여요.
카톡 대화는 어떻게 가져오나요?

💻 PC 카카오톡 (추천)

  1. 정리할 단톡방을 열어요.
  2. 오른쪽 위 메뉴(≡)에서 대화 내보내기를 눌러 .txt 파일로 저장해요. (버전에 따라 메뉴 위치나 이름이 조금 다를 수 있어요.)
  3. 저장한 파일을 대화 파일 불러오기로 고르거나, 입력칸에 끌어다 놓아요. 방 이름은 파일에서 자동으로 읽어요.

필요한 메시지만 넣고 싶으면 말풍선을 마우스로 끌어서 선택하고 Ctrl+C로 복사한 뒤 붙여넣어도 돼요.

📱 휴대폰 카카오톡

  1. 단톡방 → 오른쪽 위 메뉴(≡) → 설정(톱니바퀴) → 대화 내용 내보내기 → 텍스트만 보내기
  2. 메일이나 ‘나와의 채팅’으로 보낸 뒤, 그 파일을 열어 내용을 복사해서 붙여넣어요.

💡 알아두면 좋아요

  • 이미 넣은 메시지는 다시 넣어도 두 번 들어가지 않아요. 매일 대화 전체를 내보내서 넣어도 괜찮아요. (방 이름은 매번 똑같이 써 주세요.)
  • 말풍선 하나만 복사해서 넣어도 돼요. 이름이나 시간이 없으면 ‘날짜가 안 적혀 있으면’에 고른 날짜로 정리돼요.
  • 사진으로 올린 발주서는 글자가 아니라서 읽지 못해요. 사진이 몇 장 있었는지는 알려 드려요.

🤖 ‘AI에게 맡길 글’은 언제 쓰나요?

말투가 제각각이라 자동 정리가 잘 안 될 때 써요. 버튼을 누르면 정리 규칙과 고른 기간의 대화 원문이 함께 복사돼요. Claude나 ChatGPT 대화창에 붙여넣기만 하면 표로 정리해 줘요.

거래처 정보 같은 회사 자료를 AI에 넣어도 되는지는 먼저 확인해 주세요.

⚙️ 설정 (구분 단어 · 단위 · 데이터 지우기)

설정은 앞으로 넣는 대화부터 적용돼요. 이미 넣은 대화에 적용하려면 ‘저장된 대화 다시 정리’를 눌러 주세요. 표에서 직접 고친 내용은 그때 사라져요.

넣은 대화와 정리한 표는 이 컴퓨터의 브라우저에만 저장돼요. 여러 사람이 같이 쓰는 컴퓨터라면 다 쓴 뒤 설정에서 ‘모든 데이터 지우기’를 눌러 주세요.
